## 1. Что за проект

Инвестиционный калькулятор: **банковский**, **розничный** и **валютный** калькуляторы
с расчётом прибыли, доходности и НДФЛ (прогрессивные ставки). Vanilla-фронт + Express-прокси
к официальным данным ЦБ РФ. Деплой — Docker.

Подробно: `README.md`, `project_overview.md`.

## 2. Стек (фактический, из `package.json` и исходников)

| Слой | Технологии |
|---|---|
| Фронт | **vanilla HTML/CSS/JS** — без сборщика, без TypeScript, без UI-фреймворка |
| Бэк | **Node 18 + Express 4** (CommonJS), один файл `server.js`, порт `process.env.PORT \|\| 7777` |
| Интеграции | ЦБ РФ: `https://www.cbr.ru/hd_base/KeyRate/` (HTML), `/scripts/XML_daily.asp` (XML) |
| Деплой | Docker (`Dockerfile` node:18-alpine, `docker-compose.yml`) |
| Дев-зависимости | `nodemon` (только авто-рестарт) |

## 5. Команды (только РЕАЛЬНО работающие)

| Действие | Команда | Что проверяет |
|---|---|---|
| Запуск | `npm start` (=`node server.js`) | сервер поднимается на :7777 (или `process.env.PORT`) |
| Дев | `npx nodemon server.js` | авто-рестарт при правках |
| Проверка синтаксиса | `node --check server.js && node --check public/script.js` | **только** синтаксис JS; не ловит браузерные глобалы и runtime |
| Сборка образа | `docker build .` | полный деплой-тест |
| Smoke эндпоинтов | `curl -s localhost:7777/api/cbr-key-rate` и `/api/cbr-rates` | ручная проверка прокси |
| Существует ли id-контракт | `grep -nE "getElementById\('([^']+)'\)" public/script.js` | синхронизация HTML↔JS |

`npm test` = `echo "Error: no test specified" && exit 1`. **Не запускай** как проверку — он всегда падает.
Тестов нет → критические расчёты проверяются **ручными кейсами** (входные числа → ожидаемые суммы).

## 6. Конвенции кода (Hard rules)

1. **Размер:** новый/изменённый файл **< 300 строк**, функция **< 80 строк** — иначе реджект.
   `public/script.js` = 567 строк — техдолг; любой новый код в нём обязан компенсировать
   дроблением, а не приростом.
2. **Чистая бизнес-логика.** Функции-расчётчики (`calculateTax`, и др.) принимают число,
   возвращают число и **не трогают** `document.*`. Образец — `calculateTax(profitByYear, maxBalance, cbrRate)`.
   DOM читается/пишется только в обработчиках.
3. **DOM-ID — контракт HTML↔JS.** Фронт жёстко завязан на `getElementById(...)`. При любой правке
   форм/результатов синхронизируй `public/index.html` и `public/script.js`; пропуск id = тихая поломка.
4. **Магические числа → именованные константы** вверху модуля. Образец: `TAX_FREE_MAX = 1_000_000`,
   `RATE_13 = 0.13`. Дефолты сервера (`DEFAULT_PORT = 7777`, `cachedKeyRate = 21`, `User-Agent`) — то же самое.
5. **UI-текст без хардкода вразброс** — единый объект `const UI_TEXT = {...}` (без i18n-фреймворка).

## 7. Запреты (редижект на ревью)

- `alert()` в продакшен-путях (валидация форм) → заменить на inline-сообщение в DOM.
- `element.innerHTML = ...` с непроверенным/пользовательским/внешним контентом.
- `fetch(...)` без `AbortController`/таймаута — внешние вызовы могут зависнуть.
- Тихие `.catch(() => {})` — всегда контекст или пользовательское сообщение.
- `console.log` пользовательских данных (PII).
- Секреты/env в `public/` — попадут в браузер. (Сейчас секретов нет — не заведи.)

## 8. Известные дефекты / техдолг (по приоритету)

1. `fetch` к ЦБ без `AbortController`/таймаута — может зависнуть поток запроса.
2. `/api/cbr-rates` бьёт ЦБ **на каждый запрос** (нет кеша) → риск блокировки IP + медленно.
3. `showModal()` льёт собранную строку в `innerHTML` — потенциальная XSS-поверхность.
4. Глобальный мьютабельный `cachedKeyRate` → гонка при `?refresh=true` (параллельные запросы).
5. Валидация форм через `alert()` — плохой UX.
6. `public/script.js` (567 строк) — дробить по калькуляторам.
