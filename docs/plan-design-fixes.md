# Дополнение-исправление — заголовки вне форм + унификация размеров

> Дельта-ТЗ к `docs/plan-design-twocolumn.md`. Выявлено архитектором при ревью незакоммиченной
> работы кодера: 2 явных дефекта + 1 нарушение требования заказчика. Кодер выполнил базовый layout,
> но допустил ошибки. Здесь — точные правки для исправления.

---

## 🔴 Дефекты, найденные архитектором (обязательно исправить)

### Дефект 1 (КРИТИЧНО): копипаст-баг в заголовках калькуляторов

Во **всех 4** калькуляторах `calculator-title` = **«Банковский калькулятор»** (проверено grep по
`index.html`). Кодер скопировал банк-секцию 4 раза и не поменял текст. На вкладке «Металлы»
пользователь видит «Банковский калькулятор» — это явная поломка UX.

**Фактическое состояние (`index.html`, строки 14/13/12/11 в каждой секции):**
- bank → «Банковский калькулятор» ✓ (верно)
- retail → «Банковский калькулятор» ❌
- currency → «Банковский калькулятор» ❌
- metals → «Банковский калькулятор» ❌

### Дефект 2: `calculator-title` внутри `.calc-form`

Текущая структура (во всех 4):
```html
<div class="calc-layout">
    <div class="calc-form">
        <h2 class="calculator-title">...</h2>   ← ВНУТРИ формы (неправильно)
        <div class="invest-..."> ... поля ... </div>
    </div>
    <div class="calc-result"> ... </div>
</div>
```
Заказчик требовал: **названия вынести ВНЕ форм** — над двухколоночной раскладкой, не в левой колонке.

### Дефект 3 (уточнение): «унифицировать размеры форм» не зафиксировано явно

Текущий grid `grid-template-columns: 360px 1fr` фиксирует форму в 360px — это жёстко, а не
«унифицировано». Требование заказчика: все 4 формы **одинаковой ширины** (чтобы визуально
консистентно), но 360px может быть узко для 11-полевых (валюта/металлы).

## 📋 ТЗ на исправление

### 1. Вынести `calculator-title` ВНЕ форм (`index.html`, все 4 калькулятора)

**Стало (правильно):**
```html
<div class="calculator-container">
    <h2 class="calculator-title">...</h2>        ← ВЫНЕСЕН над calc-layout
    <div class="calc-layout">
        <div class="calc-form">
            <div class="invest-..."> ... поля ... </div>
        </div>
        <div class="calc-result"> ... </div>
    </div>
</div>
```

`calculator-title` теперь на уровне `.calculator-container`, над `.calc-layout`. Виден на всю
ширину калькулятора (не только левой колонки). Удалить дублирующий title из `.calc-form`.

### 2. Исправить тексты заголовков (Дефект 1)

| Вкладка | Текст `calculator-title` |
|---|---|
| bank | Банковский калькулятор |
| retail | Ретейл калькулятор |
| currency | Калькулятор валюты |
| metals | Калькулятор драгметаллов |

Тексты взять из текущих `<h1>` старого макета (или из AGENTS.md §1 — там перечислены 4 калькулятора).

### 3. Унифицировать ширину форм (`src/styles/layout.css`)

Текущий `360px 1fr` заменить на консистентное значение, которое вмещает 11-полевые формы
(валюта/металлы) без переноса меток:

```css
.calc-layout {
    display: grid;
    grid-template-columns: minmax(340px, 420px) 1fr;
    gap: 2rem;
    align-items: start;
}
```

**Обоснование:** `minmax(340px, 420px)` — форма 340–420px (вместит длинные лейблы типа
«Курс покупки валюты (₽ за ед.)»), правая колонка — всё остальное. Все 4 формы **одинаковой
ширины** (один grid для всех) — это и есть «унификация». НЕ `360px` жёстко — адаптив в диапазоне.

### 4. Стилизация вынесенного title (`src/styles/components.css` или `layout.css`)

`.calculator-title` теперь на верхнем уровне — добавить отступ снизу, центрирование:
```css
.calculator-title {
    text-align: center;
    margin-bottom: 1.5rem;
    color: var(--color-text-primary);
    font-size: 1.4rem;
    font-weight: 700;
}
```
(Убрать старые правила `.calculator-title`, если они были привязаны к `.calc-form`.)

## 🛡 Контракт (НЕ ломать)

- Все `id`, `onclick`, классы `invest-*` — на месте. Перенос title — структурная правка, расчёты
  не затрагивает.
- `calculator-title` — **не** имеет id и не используется в TS (проверено: только визуальный
  заголовок). Перенос безопасен для JS-контракта.
- После сборки — обязательная ручная проверка: заголовки корректны на всех 4 вкладках.
